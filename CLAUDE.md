# CLAUDE.md — GLOCK project context

You are working on **GLOCK** (`teslasolar/ACGGLOCK`) — the AI Craftspeople
Guild Clock. A static GitHub Pages app + a daily GitHub Action.

## Architecture (one-liner)

Static HTML + ES modules in `src/` + JSON in `api/` + `tick.yml` Action.
No build step. No deps. Pages fetch JSON, render canvas + DOM.

## Invariants

- Six shift types map to six rings, indexed in `TYPES` order. Don't reorder.
- The 7th "ring" on the canvas is the **total** (sum of the other six).
- Bloom uses primes [2,3,5,7,11,13,17]; primorial cap = 510510.
- Anti-gaming: max 12 h, min 5 min, no overlap, no future dates, type required.
- Streak windows: <7d active, 8–14d cooling, ≥15d dormant. Dormant resets streak to 0.
- The Action commits as `glock-bot <glock@acg>` with message `⚒ tick YYYY-MM-DD`.
- Members carry `name`, `handle`, `role`, `location`, `timezone` (IANA, null = unknown).
  Use `?` / null for unknown rather than guessing.

## When you change the schema

If you add a field to `Shift`, `Member.clock`, or `Streak`:
1. Update `api/*.json` seed data.
2. Update `tests/run.js` schema check (`need = [...]`).
3. Update `tests/glock.test.yml` `fields:` list.
4. Update `tick.js` if the field is computed.
5. `npm test` must pass before commit.

## Common tasks

- **Add a shift type** → can't (six rings is structural). Use `domain` instead.
- **Add an achievement** → append to `api/config.json` AND `src/achievements.js`.
- **Tune a window** → edit `api/config.json.streak`. Engine code reads from JSON
  where possible; some constants in `clock-engine.js` may need updating.
- **New page** → make `foo.html` + `src/main-foo.js`, call `mountChrome('foo')`,
  add the slug to `nav.js` link list.
