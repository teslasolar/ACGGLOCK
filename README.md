# ⚒ ACGGLOCK · Guild Clock

> `clock(forge(charter(manifesto(guild(craft)))))`
> the repo is the clock · every commit is a tick

GLOCK is the AI Craftspeople Guild's time-aware activity tracker.
Review Forge tracks **what** was done. GLOCK tracks **when**, **how long**,
and **how consistently**.

## Pages

| Page                | Purpose                                              |
|---------------------|------------------------------------------------------|
| `index.html`        | Dashboard: aggregate clock face + leaderboard        |
| `clock.html`        | Personal clock: punch in/out + session log           |
| `shifts.html`       | Calendar of shifts (past + scheduled)                |
| `forge-sync.html`   | Review Forge bridge: time per review/submission      |

## Data

- `api/manifest.json` — members + per-member clock state (rings, fold, sig)
- `api/shifts.json` — shift log (one record per clock-in/out)
- `api/streaks.json` — current/longest streak per member
- `api/config.json` — shift types, anti-gaming rules, achievements
- `api/leaderboard.json` — generated by tick (hours desc, streak desc)

## Run

```sh
npm run tick     # streaks + decay + bloom + leaderboard
npm test         # ACG-TEST suite (8 checks)
npm run serve    # local static server
```

The `tick` is also a GitHub Action (`.github/workflows/tick.yml`) that runs
daily at 06:00 UTC, recomputes everything, and pushes a `⚒ tick YYYY-MM-DD`
commit. **The repo history is the clock.**

## Anti-gaming

| Rule                          | Why                                  |
|-------------------------------|--------------------------------------|
| Max 12 h / Min 5 min          | No bot-length or micro shifts        |
| Same-type cooldown 30 min     | No rapid re-clock for point splits   |
| Type required on clock-in     | No untyped time                      |
| No overlapping shifts         | One clock at a time                  |
| Future-dated shifts rejected  | The clock only goes forward          |
| Dormant after 15 days         | Consistency over bursts              |

## The Rule

> Time spent reviewing is as visible as time spent publishing.
